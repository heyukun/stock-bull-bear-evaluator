# 股票多空因子评估专家 (stock-bull-bear-evaluator)

对用户输入的公司 / 股票进行 **14 个因子的系统性多空评估**（估值因子区分成长/价值/周期股方法），覆盖 A 股（sh/sz/bj）与港股（hk）。

当用户说「评估 XX 的多空」「XX 多空分析」「分析 XX 股票多空因子」「多空评估：公司名」时触发。

## 核心能力

- **14 因子三时间框架评估**：每个因子独立给出「当前多空 / 中期展望(3-6M) / 长期评估(3Y)」三个判断，避免混为一谈。
- **前置筛选关卡**：全量评估前四道关卡（高权重因子利空筛查 + 长期整体评分 ≥4 分），任一触发即终止流程。
- **尾部风险熔断**：偿债/审计/质押/客户集中度四项红线，触发任一项综合多空评分记 -99（评级同时封顶「看空」）。
- **利空因子深挖**：针对利空 / 中性偏空因子，寻找公司应对措施、定义可量化跟踪指标，并通过网络搜索验证最新进展。
- **加权多空评分**：-9~+9 分制（中性=0，方向档位叠加 S/A/B 动能分档）、三时间框架加权、五档评级，由脚本自动计算，保证可追溯。

## 快速开始

1. 将本 skill（github 链接）发送给你的 AI 编程助手（如 Kimi Code），让它将本 skill 安装到其 skill 目录。
2. 安装完成后，直接对 AI 说：

```
/stock-bull-bear-evaluator 公司名
```

即可开始评估（例如 `/stock-bull-bear-evaluator 比亚迪`）。
