# 加权多空评分算法（三时间框架）

本文件定义多空评级系统的量化打分规格：分值映射、因子权重、时间框架权重、评级阈值与长期评估判定标准。所有参数以 [../config/scoring-config.json](../config/scoring-config.json) 为唯一权威来源，便于调整与回测。

---

## 1. 算法总览

```
因子得分 s_i ∈ [1, 10]          （10 = 强烈看多，1 = 强烈看空，5.5 = 中性）
框架得分 S_f = Σ (s_i × w_i,f)   （w_i,f = 因子 i 在框架 f 的权重，Σw_i,f = 100%）
综合总分 C   = Σ (S_f × W_f)     （W_f = 时间框架 f 的权重，ΣW_f = 100%）
评级         = 按 C 对照阈值表判定（强烈看多/看多/中性/看空/强烈看空）
```

三个时间框架：

| 框架 | 含义 | 默认权重 |
|------|------|----------|
| current | 当前多空状况（基于当前事实） | 30% |
| mid | 未来 3-6 个月中期展望 | 40% |
| long | 未来 3 年长期评估 | 30% |

默认中期权重最高：3-6 个月窗口与季报验证节奏对齐，是可验证性最强的判断；当前状况已部分反映在价格中，长期判断不确定性最大。三框架权重独立于因子权重，均可在配置中调整。

## 2. 分值范围与档位映射

**1-10 分制，低分看空、高分看多，中点 5.5 为中性。**

默认档位映射（配置键 `level_scores`）：

| 档位 | 分值 | 适用框架 |
|------|------|----------|
| 利多 | 9.0 | current / long |
| 中性偏多 | 7.0 | current / long |
| 中性 | 5.5 | current / long |
| 中性偏空 | 4.0 | current / long |
| 利空 | 2.0 | current / long |
| 向好 | 9.0 | mid |
| 不明朗 | 5.5 | mid |
| 不佳 | 2.0 | mid |

**强度微调（可选）**：评估者可在档位基准分上 ±1 分（如"强利多"给 10、"弱利多"给 8），最终结果 clamp 到 [1, 10]。使用微调时须在说明中给出依据，保证可复现。回测时建议关闭微调、纯用档位映射，保证一致性。

## 3. 因子权重（按时间框架独立配置）

权重设计逻辑：**交易类因子（筹码/资金/舆论）在短框架重要、长框架衰减；结构类因子（行业/竞争/壁垒/替代品）在长框架权重上升。** 每个框架内 14 因子权重之和 = 100%。

| # | 因子 | 当前权重 | 中期(3-6M)权重 | 长期(3Y)权重 |
|---|------|---------|---------------|-------------|
| 1 | 宏观 | 8% | 8% | 8% |
| 2 | 社会舆论 | 5% | 4% | 2% |
| 3 | 行业 | 10% | 12% | 14% |
| 4 | 政策 | 8% | 10% | 10% |
| 5 | 上游 | 7% | 9% | 7% |
| 6 | 下游 | 10% | 12% | 12% |
| 7 | 竞争对手 | 8% | 8% | 12% |
| 8 | 替代品/新技术颠覆 | 6% | 6% | 10% |
| 9 | 进入壁垒 | 6% | 5% | 12% |
| 10 | 公司资本操作 | 6% | 6% | 4% |
| 11 | 筹码多空 | 8% | 6% | 2% |
| 12 | 资金多空 | 10% | 7% | 2% |
| 13 | 业绩动能 | 8% | 7% | 5% |
| 14 | 估值 | 8% | 10% | 6% |

说明：筹码/资金在长期框架仍保留 2% 而非 0，是为保留输入接口（若确无长期意义，评估时给"中性"即可，效果等价）。业绩动能是 1-3 季度战术信号，长期框架同样默认"中性"（见第 5 节因子 13），保留 5% 权重仅为保留输入接口。估值在中期权重最高（10%）：3-6 个月是估值消化/压缩兑现最快的窗口；长期降至 6%（长期收益由成长主导，买入估值的影响随持有期摊薄，但不消失）。

## 4. 评级阈值

综合总分与各框架得分均按同一阈值表判定（配置键 `rating_thresholds`，区间为左闭右开）：

| 综合总分 | 评级 |
|----------|------|
| ≥ 8.0 | 强烈看多 |
| 6.5 – 8.0 | 看多 |
| 4.5 – 6.5 | 中性 |
| 3.0 – 4.5 | 看空 |
| < 3.0 | 强烈看空 |

### 4.1 熔断封顶（优先于评级阈值）

输入 JSON 含非空 `circuit_breakers` 时，综合评级**封顶**为 `config.circuit_breaker.cap_rating`（当前配置：看空）：原始评级照常计算并展示，但最终评级不高于封顶档。

**设计理由**：熔断项（偿债红线/审计与治理/大股东质押/客户集中度，定义见 SKILL.md 第 1.6 步）是一票否决型尾部风险，若参与加权平均，可能被其余 13 个因子的利多稀释至"中性"甚至"看多"——这正是加权评分最大的盲区。熔断不参与加权，只封顶结果。

## 5. 长期（3 年）评估判定指引

长期评估用五档（利多/中性偏多/中性/中性偏空/利空），聚焦 3 年维度的方向而非短期波动：

| # | 因子 | 长期看多信号 | 长期看空信号 |
|---|------|--------------|--------------|
| 1 | 宏观 | 利率/通胀长期中枢稳定或下行，流动性周期处于宽松大周期 | 长期通胀中枢抬升，紧缩大周期 |
| 2 | 社会舆论 | （长期基本不适用，默认中性） | （同左） |
| 3 | 行业 | 行业 3 年 CAGR 向上、TAM 扩张、供需格局持续优化 | 行业 3 年 CAGR 下行、产能长期过剩 |
| 4 | 政策 | 支持性政策具持续性且累积效应递增 | 打压性/收紧性政策为长期方向 |
| 5 | 上游 | 上游资源处于 3 年供给释放周期（成本下行） | 上游 3 年供给约束周期（成本上行） |
| 6 | 下游 | 终端需求 3 年复合增长、渗透率空间大 | 需求见顶回落、渗透率天花板临近 |
| 7 | 竞争对手 | 格局 3 年趋集中、公司份额与优势可持续扩大 | 格局趋分散、优势被持续侵蚀 |
| 8 | 替代品/新技术颠覆 | 3 年内无颠覆性路线，或公司已卡位新路线 | 3 年内替代路线大概率交叉超越且公司缺位 |
| 9 | 进入壁垒 | 壁垒 3 年持续加深（技术/规模/生态累积） | 壁垒被技术扩散/政策放开持续侵蚀 |
| 10 | 公司资本操作 | 治理优良，分红/回购常态化，管理层长期增持 | 长期依赖增发融资，治理瑕疵 |
| 11 | 筹码多空 | （长期基本不适用，默认中性） | （同左） |
| 12 | 资金多空 | （长期基本不适用，默认中性） | （同左） |
| 13 | 业绩动能 | （长期基本不适用，默认中性） | （同左） |
| 14 | 估值 | 当前估值隐含增速低于 3 年可实现成长空间（未透支）；周期股 PB 处历史低位且长期需求未衰退 | 估值已透支 3 年成长（隐含增速高于可实现空间）；周期股在盈利顶部的高市值（低 PE 假象） |

判定纪律与短期框架一致：须有依据（行业空间测算、政策周期判断、产能投资周期等），无可靠依据时如实给"中性"，不强行判断。

## 6. 使用方法

### 6.1 计算脚本

```bash
# 标准用法：输入评估 JSON，输出评分 markdown（含各框架明细与综合评级）
python3 scripts/scoring_calc.py input.json

# 指定自定义配置（回测/调参）
python3 scoring_calc.py input.json -c config/scoring-config.json

# 输出到文件
python3 scoring_calc.py input.json --md 评分结果.md

# 演示（内置示例数据）
python3 scripts/scoring_calc.py --demo

# 打印当前配置（核对权重/阈值）
python3 scripts/scoring_calc.py --print-config
```

### 6.2 输入格式

```json
{
  "company": "示例公司",
  "code": "sz000000",
  "date": "2026-08-16",
  "circuit_breakers": [
    {"item": "客户集中度红线", "evidence": "第一大客户占营收 58%（2025 年报）"}
  ],
  "factors": {
    "宏观":       {"current": "利多",     "mid": "向好",   "long": "中性偏多"},
    "社会舆论":   {"current": 7,          "mid": "不明朗", "long": "中性"},
    "估值":       {"current": "中性偏空", "mid": "不佳",   "long": "中性"},
    "...": {}
  }
}
```

- 档位字符串按 `level_scores` 映射为分值；直接写数字（1-10）则原样使用（用于强度微调或回测）。
- `circuit_breakers` 为可选项：元素为字符串或 `{item, evidence}` 对象；非空时综合评级封顶 `circuit_breaker.cap_rating`（见第 4.1 节）；无触发时省略或给空数组。
- 某框架缺失时该因子按"中性"（5.5 分）计，脚本会输出警告。
- 因子名必须与配置 `factors` 列表一致，缺因子直接报错。

### 6.3 参数调整与回测

1. 所有权重/映射/阈值均在 `config/scoring-config.json`，改动配置不改代码。
2. **配置变更须记录**：在配置文件 `changelog` 数组中追加一行（日期 + 变更内容 + 理由），保证回测可追溯。
3. 回测建议：关闭强度微调（纯档位映射）；固定同一版配置对历史多期评估重算；对比评级结论与后续 6 个月/3 年实际走势的命中率。
4. 校验规则（脚本自动执行）：每框架因子权重和 = 100%（容差 ±0.0001）；框架权重和 = 100%；档位映射覆盖全部合法档位；阈值严格递减且覆盖 [0, 10]。

## 7. 评分纪律

1. **档位先行、分数跟随**：先按 factor-definitions.md 判档位，再由映射得分。不允许跳过档位直接"拍分数"。
2. **评分不改定性结论**：加权总分是定性判断的汇总呈现，当总分与定性分析明显矛盾时（如框架间严重背离），以定性分析为准并在报告中标注背离，不得用分数掩盖分歧。
3. **同一报告内配置一致**：一次评估全程使用同一版配置；跨期对比须注明配置版本（changelog 最新条目）。
4. **熔断优先于评分**：`circuit_breakers` 非空时综合评级封顶 `circuit_breaker.cap_rating`（见第 4.1 节），原始评级与触发项照常展示，不得用分数掩盖熔断事实。
