# 加权多空评分算法（三时间框架）

本文件定义多空评级系统的量化打分规格：分值映射、因子权重、时间框架权重、评级阈值与长期评估判定标准。所有参数以 [../config/scoring-config.json](../config/scoring-config.json) 为唯一权威来源，便于调整与回测。

---

## 1. 算法总览

```
因子得分 s_i ∈ [-9, +9]         （+9 = 最强烈看多，-9 = 最强烈看空，0 = 中性）
框架得分 S_f = Σ (s_i × w_i,f)   （w_i,f = 因子 i 在框架 f 的权重，Σw_i,f = 100%）
综合总分 C   = Σ (S_f × W_f)     （W_f = 时间框架 f 的权重，ΣW_f = 100%）
评级         = 按 C 对照阈值表判定（强烈看多/看多/中性/看空/强烈看空）
```

三个时间框架：

| 框架 | 含义 |
|------|------|
| current | 当前多空状况：以**历史情景基线**为锚（默认近 5 年分布/常态区间，因子另有约定从其约定），方向档位 = 当前状态在历史基线中的位置，S/A/B = 相对历史的方向/动量变化 |
| mid | 中期展望：以**当前情景为起点**，未来 3-6 个月相对当前的方向/动量变化 |
| long | 长期评估：以**当前情景为起点**，未来 3 年相对当前的方向/动量变化 |

各框架权重 W_f 以配置文件 `frames.<frame>.weight` 为准（本文不重复列出数值）。默认配置中中期权重最高：3-6 个月窗口与季报验证节奏对齐，是可验证性最强的判断；当前状况已部分反映在价格中，长期判断不确定性最大。三框架权重独立于因子权重，均可在配置中调整。

## 2. 分值范围与档位映射

**-9 ~ +9 分制，负分看空、正分看多，0 为中性。**

### 2.0 档位判定程序（两轴矩阵，强制；先于分值映射执行）

定档不是整体"拍档位"，而是**两个独立步骤的机械执行**：先定方向档位（轴 1），再定 S/A/B 动能后缀（轴 2）。两步不可合并、不可跳过。

**框架锚定（轴 1/轴 2 的比较基准随框架切换，强制）**：

| 框架 | 轴 1 比较基准 | 方向档位含义 | 轴 2（S/A/B）含义 |
|------|---------------|--------------|-------------------|
| 当前 | **历史情景基线**（默认近 5 年分布/常态区间；因子自带基线约定者从其约定，如估值近 5 年分位、融资余额近 1 年分位） | 当前状态在历史基线中的**位置**（显著优于历史常态 → 利多侧；显著劣于 → 利空侧；区间内 → 中性/偏档） | 相对历史基线的**方向/动量变化**（改善/恶化在加速 → S，减速 → B） |
| 中期 | **当前情景** | 未来 3-6 个月相对当前的**方向变化**（向好/不佳；不关注绝对水平，只关注变化） | 该预期变化的**加速/减速** |
| 长期 | **当前情景** | 未来 3 年相对当前的**方向变化** | 3 年尺度方向性力量的**累积/衰减** |

- 信号清单制下，当前框架各信号的 +1/0/-1 以**历史/常态基线为参照**判定（"上行/下行"类信号指当前状态处于历史分布的有利/不利区间，而非单纯的边际变动；政策类因子以"无政策干预的中性环境"为基线）；中期/长期框架的信号含义是对当前情景的前瞻变化。
- 证据强度标尺下，当前框架的"证据"须先换算为相对历史基线的位置（如"行业景气高"须回答"处于历史什么分位/区间"），不得只凭绝对水平定档。

**轴 1 · 方向档位**：两条路径，按因子是否已配信号清单选择——

1. **信号清单制（因子 3/4/6/13 强制使用）**：因子 3/4/6 的信号清单见 factor-definitions.md 3b/4d/6b；因子 13 的信号清单即 momentum-check.md 的 14 项检查（预警计数映射，是本制度的参照实现）。规则：
   - 每个子信号独立判 `+1 / 0 / -1`（有明确正向证据 +1，有明确负向证据 -1，无证据/多空抵消 0）；
   - 加总得分 T 映射方向档位：**T ≥ +2 → 利多；T = +1 → 中性偏多；T = 0 → 中性；T = -1 → 中性偏空；T ≤ -2 → 利空**；
   - 信号得分与逐项判定须写入因子说明（见下方判定三元组）。
2. **证据强度标尺（未配信号清单的因子使用）**：

| 档位 | 通用判定条件 |
|------|--------------|
| 利多 / 利空 | 存在**已发生、可直接量化到公司层面**的证据（能量化到收入/成本/份额/准入方向），且来源 T2+ |
| 中性偏多 / 中性偏空 | 方向性信号存在，但间接（传导链条长）、幅度有限、或持续性未验证 |
| 中性 / 不明朗 | 无信号 / 多空信号并存抵消 / 无可靠前瞻 |

**轴 2 · S/A/B 动能后缀（变化率标尺）**：方向档位确定后，只回答一个问题——该方向核心驱动变量在**最近一个观测周期**的变化率：

- **S**：出现新的强化事件，或核心指标加速（同比/环比增速的二阶变化为正、事件密度上升）；信号清单制下，信号总分较上一评估期**上升**（首次评估时以核心信号近 3 个月趋势加速为准）。
- **B**：出现减速或反向信号（增速回落、事件密度下降、缓和证据出现）；信号清单制下，信号总分较上一评估期**下降**。
- **A**：以上皆无（默认档；无可靠动能信号时一律 A，不强行标 S/B）。

**判定三元组纪律（强制）**：每个档位判定必须在因子说明中携带三元组——**方向证据（或信号得分明细）/ 动能信号 / 信源+日期**。缺任一元组的档位视为未判定，须补齐后方可进入加权评分。可执行度的本质是可复核：三元组使任何档位可被第三方独立复算。

### 2.1 S/A/B 动能分档（通用规则，先定方向档位、再定动能分档）

除「中性」「不明朗」外，每个方向档位必须携带 S/A/B 后缀，表达该方向判断的**动能/趋势**：

| 后缀 | 含义（利多侧） | 含义（利空侧） |
|------|----------------|----------------|
| **S** | 方向成立，且利多动能/趋势在**加强** | 方向成立，且利空动能/趋势在**加强**（恶化加剧） |
| **A** | 方向成立，但动能/趋势**平稳或不明朗** | 方向成立，但动能/趋势**平稳或不明朗** |
| **B** | 方向成立，但利多动能/趋势在**减弱**（衰竭迹象） | 方向成立，但利空动能/趋势在**减弱**（缓和迹象） |

判定顺序：**先按 factor-definitions.md 定方向档位（利多/中性偏多/…），再按动能/趋势定 S/A/B**。动能依据须为可观测信号（数据趋势、事件节奏、订单/份额/价格的方向性变化），不可凭空标注；无动能信号时默认 A。中性偏空 S 表示"偏空动能加强、向利空演进"（得分最低 -4），中性偏空 B 表示"偏空缓和、向中性回归"（-2）；中性偏多同理镜像。

### 2.2 档位分值映射（配置键 `level_scores`）

| 档位 | 分值 | 适用框架 |
|------|------|----------|
| 利多S | 9.0 | current / long |
| 利多A | 7.0 | current / long |
| 利多B | 5.0 | current / long |
| 中性偏多S | 4.0 | current / long |
| 中性偏多A | 3.0 | current / long |
| 中性偏多B | 2.0 | current / long |
| 中性 | 0.0 | current / long |
| 中性偏空B | -2.0 | current / long |
| 中性偏空A | -3.0 | current / long |
| 中性偏空S | -4.0 | current / long |
| 利空B | -5.0 | current / long |
| 利空A | -7.0 | current / long |
| 利空S | -9.0 | current / long |
| 向好S | 9.0 | mid |
| 向好A | 7.0 | mid |
| 向好B | 5.0 | mid |
| 不明朗 | 0.0 | mid |
| 不佳B | -5.0 | mid |
| 不佳A | -7.0 | mid |
| 不佳S | -9.0 | mid |

全序列单调：9 / 7 / 5 / 4 / 3 / 2 / 0 / -2 / -3 / -4 / -5 / -7 / -9。

**强度微调（可选）**：评估者可在档位基准分上 ±1 分（如"利多S 且极强"给 9.5、"利多B 接近偏多"给 4.5），最终结果 clamp 到 [-9, +9]。使用微调时须在说明中给出依据，保证可复现。回测时建议关闭微调、纯用档位映射，保证一致性。

## 3. 因子权重（按时间框架独立配置）

权重设计逻辑：**交易类因子（筹码/资金/舆论）在短框架重要、长框架衰减；结构类因子（行业/竞争/壁垒/替代品）在长框架权重上升。** 每个框架内 14 因子权重之和 = 100%。

各因子在三个框架下的具体权重数值**不在本文维护**，唯一来源为配置文件 `frames.<frame>.factor_weights`（可用 `python3 scripts/scoring_calc.py --print-config` 查看当前生效值）。

说明：长期框架仅保留行业/政策/竞争对手/替代品/进入壁垒 5 个结构类维度（v1.5.0 起，按原值等比提升，框架内和=100%），宏观/社会舆论/上游/下游/公司资本操作/筹码/资金/业绩动能/估值权重均为 0——这些维度在 3 年尺度上基本不适用，归零避免稀释长期评分。中期框架筹码/资金/业绩动能/估值权重均为 0（v1.6.0 起）——这 4 个维度不影响中期多空判断，中期评分由其余 10 个基本面维度等比加权。权重为 0 的因子在对应框架**直接跳过、不做分析**；评分输入 JSON 中可省略该框架键（脚本按中性默认计，权重 0 不影响得分）。

## 4. 评级阈值

综合总分与各框架得分均按同一阈值表判定（配置键 `rating_thresholds`，区间为左闭右开）：

| 综合总分 | 评级 |
|----------|------|
| ≥ 6.0 | 强烈看多 |
| 3.0 – 6.0 | 看多 |
| -3.0 – 3.0 | 中性 |
| -6.0 – -3.0 | 看空 |
| < -6.0 | 强烈看空 |

### 4.1 熔断评分否决（优先于评级阈值）

输入 JSON 含非空 `circuit_breakers` 时，综合评分结果直接记为 **-99**（哨兵值，在合法分制 [-9,+9] 之外，表示加权结果被一票否决，不参与阈值映射），综合评级同时**封顶**为 `config.circuit_breaker.cap_rating`（当前配置：看空）。原始加权总分与原始评级照常计算并展示，但最终评分结果为 -99、最终评级不高于封顶档。

**设计理由**：熔断项（偿债红线/审计与治理/大股东质押/客户集中度，定义见 SKILL.md 第 5 步）是一票否决型尾部风险，若参与加权平均，可能被其余 13 个因子的利多稀释至"中性"甚至"看多"——这正是加权评分最大的盲区。熔断不参与加权：触发即判 -99 并封顶结果。（v2.0.0 起哨兵值由 -1 改为 -99：-1 在新分制 [-9,+9] 内是合法分值，无法与真实评分区分。）

## 5. 长期（3 年）评估判定指引

长期评估以**当前情景为起点**，判断各因子未来 3 年**相对当前**的方向/动量变化（聚焦 3 年维度的方向而非短期波动）；用五档方向（利多/中性偏多/中性/中性偏空/利空）叠加 S/A/B 动能分档（见第 2.1 节），长期框架的 S/A/B 以 3 年尺度上方向性力量的累积/衰减为准（如壁垒加深在加速 vs 趋于平缓）。

**注**：长期框架仅评估权重 >0 的 5 个因子（行业/政策/竞争对手/替代品/进入壁垒），表中其余因子直接跳过，不做长期判定（保留备查）。

| # | 因子 | 长期看多信号 | 长期看空信号 |
|---|------|--------------|--------------|
| 3 | 行业 | 行业 3 年 CAGR 向上、TAM 扩张、供需格局持续优化 | 行业 3 年 CAGR 下行、产能长期过剩 |
| 4 | 政策 | 支持性政策具持续性且累积效应递增 | 打压性/收紧性政策为长期方向 |
| 7 | 竞争对手 | 格局 3 年趋集中、公司份额与优势可持续扩大 | 格局趋分散、优势被持续侵蚀 |
| 8 | 替代品/新技术颠覆 | 3 年内无颠覆性路线，或公司已卡位新路线 | 3 年内替代路线大概率交叉超越且公司缺位 |
| 9 | 进入壁垒 | 壁垒 3 年持续加深（技术/规模/生态累积） | 壁垒被技术扩散/政策放开持续侵蚀 |

判定纪律与短期框架一致：须有依据（行业空间测算、政策周期判断、产能投资周期等），无可靠依据时如实给"中性"，不强行判断。
## 6. 使用方法

### 6.1 计算脚本

```bash
# 标准用法：输入评估 JSON，输出评分 markdown（含各框架明细与综合评级）
python3 scripts/scoring_calc.py input.json

# 指定自定义配置（回测/调参）
python3 scoring_calc.py input.json -c config/scoring-config.json

# 输出到文件
python3 scoring_calc.py input.json --md 评分结果.md

# 演示（内置示例数据）
python3 scripts/scoring_calc.py --demo

# 打印当前配置（核对权重/阈值）
python3 scripts/scoring_calc.py --print-config
```

### 6.2 输入格式

```json
{
  "company": "示例公司",
  "code": "sz000000",
  "date": "2026-09-03",
  "circuit_breakers": [
    {"item": "客户集中度红线", "evidence": "第一大客户占营收 58%（2025 年报）"}
  ],
  "factors": {
    "宏观":       {"current": "利多A",     "mid": "向好A",   "long": "中性偏多A"},
    "社会舆论":   {"current": 3.5,         "mid": "不明朗",  "long": "中性"},
    "估值":       {"current": "中性偏空B", "mid": "不佳B",   "long": "中性"},
    "...": {}
  }
}
```

- 档位字符串按 `level_scores` 映射为分值，**必须携带 S/A/B 后缀**（如 `利多S`/`利空B`；`中性`/`不明朗` 无后缀）；直接写数字（-9 ~ 9）则原样使用（用于强度微调或回测）。
- `circuit_breakers` 为可选项：元素为字符串或 `{item, evidence}` 对象；非空时综合评分记为 -99 且综合评级封顶 `circuit_breaker.cap_rating`（见第 4.1 节）；无触发时省略或给空数组。
- 某框架缺失时该因子按"中性"（0 分）计，脚本会输出警告。
- 因子名必须与配置 `factors` 列表一致，缺因子直接报错。

### 6.3 参数调整与回测

1. 所有权重/映射/阈值均在 `config/scoring-config.json`，改动配置不改代码。
2. **配置变更须记录**：在配置文件 `changelog` 数组中追加一行（日期 + 变更内容 + 理由），保证回测可追溯。
3. 回测建议：关闭强度微调（纯档位映射）；固定同一版配置对历史多期评估重算；对比评级结论与后续 6 个月/3 年实际走势的命中率。
4. 校验规则（脚本自动执行）：每框架因子权重和 = 100%（容差 ±0.0001）；框架权重和 = 100%；档位映射覆盖全部合法档位（20 个：13 个当前/长期档位含 S/A/B 后缀 + 7 个中期档位）；阈值严格递减且覆盖 [-9, +9]。

## 7. 评分纪律

1. **档位先行、分数跟随**：先按第 2.0 节两轴判定程序定档（信号清单制因子 3/4/6/13 用信号加总映射，其余因子用证据强度标尺），再由映射得分。不允许跳过档位直接"拍分数"，也不允许跳过轴 1 直接标 S/A/B。
2. **评分不改定性结论**：加权总分是定性判断的汇总呈现，当总分与定性分析明显矛盾时（如框架间严重背离），以定性分析为准并在报告中标注背离，不得用分数掩盖分歧。
3. **同一报告内配置一致**：一次评估全程使用同一版配置；跨期对比须注明配置版本（changelog 最新条目）。
4. **熔断优先于评分**：`circuit_breakers` 非空时综合评分记为 -99 且综合评级封顶 `circuit_breaker.cap_rating`（见第 4.1 节），原始加权总分、原始评级与触发项照常展示，不得用分数掩盖熔断事实。
